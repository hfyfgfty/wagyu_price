# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

* リモートリポジトリ：ネット上に配置し複数人で共有するリポジトリ
* ローカルリポジトリ：個人が使用するために自身のPC上に配置するリポジトリ

## プッシュとマージの違いは何でしょうか？

* プッシュ：ローカルの変更履歴をリモートリポジトリへ送る作業
* マージ：分けて行っていた作業を一つに統合する作業

## コミットとプッシュの違い

* コミット：自分のパソコン内だけに、変更履歴を記録する操作
* プッシュ：コミットした自分の捜査記録を、ネット上へ送信する操作

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

* 変更内容を一目で見てわかるようにする

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

* 他者からのチェックが入るかどうか

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

1. 先にマージされた変更内容を取り込む
2. 後にマージしようとしている変更内容を取り込む
3. どちらの変更内容も取り込む

これは working ブランチだけの変更です。
